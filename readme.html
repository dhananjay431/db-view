db-view

A browser document viewer library for rendering common documents, images, spreadsheets, text files, emails, SVGs, and TIFF files from Base64 data.

Overview

db-view provides a simple db.show() API that renders a document inside any HTML container by detecting the file extension. It includes built-in styles, zoom controls for most formats, safe text handling, iframe-based PDF display, spreadsheet table rendering, DOC/DOCX rendering, and cleanup helpers for memory management.

Supported Documents and Files

The library currently supports 14 file extensions across 10 document groups:

  • PDF

    PDF Documents

    Renders PDF files in an iframe viewer.

  • PNG

    PNG Images

    Displays Base64 PNG images with viewer styling.

  • JPGJPEG

    JPEG Images

    Displays JPG/JPEG images with zoom support.

  • EML

    Email Files

    Renders email message content from EML files.

  • HTML

    HTML Documents

    Displays HTML content using the library HTML renderer.

  • XLSXXLSCSV

    Spreadsheets

    Converts spreadsheet data into readable HTML tables.

  • DOCXDOC

    Word Documents

    Renders Word documents using the document renderer.

  • TXTXML

    Text and XML

    Displays text safely inside a <pre> element.

  • SVG

    SVG Images

    Renders SVG content inside the viewer container.

  • TIFTIFF

    TIFF Images

    Supports TIFF rendering with previous/next page controls for multi-page TIFF files.

Basic Browser Usage

Add the bundled script to your page, create a container, and call db.show(base64Data, fileName, containerId). 

<!DOCTYPE html>
<html>
<head>
  <title>db-view Example</title>
</head>
<body>
  <input type="file" id="fileInput" />
  <div id="viewer"></div>

  <script src="dist/db-view.js"></script>
  <script>
    document.getElementById("fileInput").addEventListener("change", function (event) {
      const file = event.target.files[0];
      if (!file) return;

      const reader = new FileReader();
      reader.onload = function () {
        // reader.result is a Data URL. db.show also accepts raw Base64.
        db.show(reader.result, file.name, "viewer");
      };
      reader.readAsDataURL(file);
    });
  </script>
</body>
</html>

ES Module Usage

The source exports the main db object and individual renderers. 

import { db } from "./src/index.js";

const base64Data = "...";
db.show(base64Data, "sample.pdf", "viewer");

You can also import specific renderers if your build setup supports it: 

import { pdf, png, jpeg, xlsx, doc, txt, svg, tiff } from "./src/index.js";

Main API

Method Description Example
db.show(data, file, id, options) Renders Base64 document data into the container whose ID is provided. db.show(base64, "report.pdf", "viewer")
db.cleanup(containerId) Cleans event listeners, canvases, iframes, blob URLs, and TIFF/PDF resources for one viewer. db.cleanup("viewer")
db.cleanupAll() Cleans all viewer containers and cached assets. db.cleanupAll()
db.getVersion() Returns the current library version string. db.getVersion()

Parameters for db.show()

Parameter Type Required Details
data String Yes Base64 document data. Data URLs such as data:application/pdf;base64,... are also accepted.
file String Yes File name with extension. The extension decides which renderer is used.
id String Yes ID of the HTML element where the document should be rendered.
options Object No Optional configuration object reserved for viewer options.

Important Notes

Tip: Always pass the correct file name extension because the library chooses the renderer from the extension.
  • Call db.cleanup(containerId) before removing a viewer from the page.
  • Call db.cleanupAll() when closing a page or clearing multiple viewers.
  • PDF files are displayed in an iframe and use the browser/PDF rendering flow.
  • Spreadsheet rendering is asynchronous internally, so large files may take a moment to appear.
  • TIFF files can include page navigation controls when multiple pages are available.
